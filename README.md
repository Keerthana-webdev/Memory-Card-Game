## Memory Card Game
A modern AI-themed Memory Card Game built using React.js, HTML, CSS, and JavaScript with animated UI and image-based cards.

---

### Features
- 🎮 AI-themed modern interface
- 🃏 Interactive memory card gameplay
- ⏱ Timer and move counter
- 📈 Multiple difficulty levels
- ✨ Smooth card flip animations
- 🖼 Dynamic themed image cards
- 🔄 Restart and replay functionality
- 📱 Responsive design

---

### Technologies Used
- React.js
- HTML5
- CSS3
- JavaScript

---

### Installation
```
1️⃣Clone the repository:
git clone https://github.com/Keerthana-webdev/Memory-Card-Game.git
cd Memory_Card_Game

2️⃣Install dependencies:
npm install

3️⃣Run the project:
npm start
```
